# RutaMX — instrucciones para Claude Code

Las instrucciones completas para trabajar en este proyecto están en
[`AGENTS.md`](AGENTS.md) — son las mismas para Claude (Angel) y Codex
(Roberto), para que ninguna IA trabaje "a lo tonto" por fuera del
contexto que ya se decidió entre los dos.

**Lee `AGENTS.md` y los archivos de [`bitacora_proyecto/`](bitacora_proyecto/)
(01, 02 y 03 siempre; el 04 si tocas destinos, etiquetas, restaurantes u
hoteles; el 05 si tocas el frontend) antes de proponer un plan o tocar código.** Después de cualquier cambio
real, actualiza el archivo de `bitacora_proyecto/` que corresponda — el
detalle de cuál va en cuál está en `AGENTS.md`.
